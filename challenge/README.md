# 0x00. Fix My Code Challenge

## Description

This project is a new type of exercise where we dive into an existing codebase and fix it, rather than write it from scratch. Some files are in languages you may not be fully familiar with, the goal is not to rewrite everything, but to locate and fix the specific bug in each file.

## Background Context

`Fix my code` challenges us to debug pre-existing code across multiple languages (Python, JavaScript, Ruby, C). Each task starts from the [Fix_My_Code_Challenge](https://github.com/hs-hq/0x00-Fix_My_Code_Challenge) repository.

## Requirements

### General

- Allowed editors: `vi`, `vim`, `emacs`
- All files compiled/interpreted on Ubuntu 20.04 LTS
- All files should end with a new line
- A `README.md` file, at the root of the project, is mandatory
